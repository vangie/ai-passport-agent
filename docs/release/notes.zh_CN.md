# AI Passport Agent v0.8.1

完成 Muse 真机配对、状态栏图标、代理自动继承与语音问答修复 · 2026-11-27

## 主要变化

- **简化 Muse 配置并修复蓝牙配对。** 网页配置台将 Muse 统一为单一「Muse」助手选项，
  SDK token 随「保存配置」一并写入；工牌「设置 → 助手 → Muse 配对」对齐官方 Link GATT
  句柄、`gadget` 设备类别与单次按键确认流程，并在配对期间保持唤醒。
- **新增 Muse 状态栏图标与代理自动继承。** 已配对的 Muse 助手在状态栏显示专属 22 × 22
  图标；未单独配置线路时自动继承设备上已有的 Shadowsocks 代理。
- **修复 ESP32-C3 上的 Muse 语音提问链路。** 单帧 Noise 负载与 NDJSON 流式事件改为原地
  解析，单帧 WebSocket 接收容量提升至 14 KB，支持多段回复链聚合，不可重试的发送失败会清理
  空白会话占位并回到主屏显示错误提示。
- **消除录音吞字并提升语音识别准确度。** 录音增量擦除改为每次单扇区（4 KB），配合 100 ms
  I2S DMA 缓冲消除每 0.5 秒擦除造成的断字；上传前自动裁切前 120 ms 唤醒满幅冲击，并执行
  80 Hz 高通滤波与人声增益归一化。

## 安装或升级

电脑用 Chrome 或 Edge 打开 <https://ai-passport-agent.codelife.me/>，USB 连接工牌，
保持「保留配置」并选择「更新固件」。应用区更新会保留已存网络、助手和设备身份。
然后在「新增助手」选择「Muse」，通过 USB 粘贴个人 Gadget SDK token 并点击「保存配置」，
再在工牌「设置 → 助手 → Muse 配对」中用 Muse App 完成绑定。网络需要代理时，
在 Muse 助手的「连接设置」中单独选择直连或 Shadowsocks。

现有网关插件保持独立版本，不需要替换或重新配对。更新固件不会自动替换或重启网关。

## 验证与限制

固件构建、合并镜像布局、主机测试、网页测试，以及真机 Muse 蓝牙配对和经 Shadowsocks 的端到端
语音问答均已验证通过。设备没有 PSRAM，应用分区接近上限，后续新增功能需要先检查体积。
