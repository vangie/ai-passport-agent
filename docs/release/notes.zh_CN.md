# AI Passport Agent v0.7.0

正式版 · 2026-11-13

## 本版重点

- **保留完整语音回复。** 疑似语音打断检查改为暂停播放游标而非丢弃音节，
  等扬声器回声消退后再确认人声，不再只依赖波形匹配。
  两种后端插件同时关闭独立的上游音频打断，避免与设备语音／按键控制竞争。
  OpenClaw 回复阶段错误不再让通话停在虚假的重连状态。
  通话页面切换由显示任务完整刷新，
  避免连接时在应用任务栈上绘制导致重启。
- **选择自己的个人 Agent。** 在 OpenClaw 之外新增 Hermes 提问与通话。
  提问使用 Hermes 原生个人 Agent 的工具、记忆及设备独立会话，不是另起一个通用聊天机器人。
  已有 OpenClaw 连接保持兼容。
- **按后端准备配置。** 网页新增助手时先选 OpenClaw 或 Hermes，再复制对应中英文提示词，
  检查插件、模型服务和安全可达入口，避免混用两种后端的安装与配对命令。
- **看清当前连接。** 设备识别认证后的后端，分别呈现平台图标和配置的助手姓名；
  图标向内缩进，避开屏幕圆角。
- **不改核心，便于升级。** Hermes 插件和私密设备授权放在核心目录之外。
  发布包新增版本化插件、哈希与来源校验，补齐 Hermes 图标许可；标签发布增加浏览器测试门禁。
  原生 App 仍仅保留源码。

## 安装与升级

从 <https://ai-passport-agent.codelife.me/> 和[上手步骤](../../README.zh_CN.md#开始使用)开始。
Hermes 需要 v0.7.0 或更新固件及对应外置插件；v0.6.0 不包含 Hermes 接入。

兼容 USB 更新保留勾选「保留配置」。首次安装或完整替换会覆盖配置，先阅读
[数据策略](../development/engineering/firmware-layout.zh_CN.md#刷写与已存数据)。
已有身份、网络、OpenClaw 插件 ID 与配对保持兼容；新增 Hermes 连接需要单独配对。
旧配置网址仍可跳转。

按后端选择主机插件：`ai-passport-openclaw-0.7.0.tgz` 或 `ai-passport-hermes-0.7.0.tar.gz`。
两种后端共用固件，压缩包为 `ai-passport-agent-firmware.tar.gz`。
核对 `SHA256SUMS.txt` 与 `release-manifest.json`；不要上传设备授权或模型密钥。

## 验证与边界

Hermes v0.22.6+481 已有实机提问／通话记录；升级后的 v0.23.1 已通过插件注册及真实运行时
适配器测试。维护者随后确认实机回归及语音打断已通过，可正式发布。
语音质量、回声与识别准确率不代表全场景验收。
通话由实时模型处理日常交流，需要任务或上下文时咨询原生 Agent，并非每句都执行完整 Agent。
两种后端均需自行配置服务商，通话另需实时语音配置；设备暂不支持交互式工具审批。

自动化声学检查完成 OpenClaw 两轮回复，未见误打断、重启或播放停顿。
仍记录到收音丢块及数秒级 ACK 延迟；响应速度和识别表现仍受网络与服务商影响。

打标签或提交社区前，先完成[发布检查清单](readiness.zh_CN.md)。
