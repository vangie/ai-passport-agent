# AI Passport Agent v0.7.5

自动关机后保持关机，按键才会唤醒 · 2026-11-16

## 本版重点

- **自动关机后保持睡眠。** 进入深度睡眠前清除残留的待机定时唤醒，只保留实体按键唤醒，因此设备不会在关机后立即自己重启。
- **保留现有闲置设置。** 息屏和关机时间仍可在设备和配置网页中调整，先后关系保持不变。

## 安装与升级

电脑 Chrome／Edge 打开 <https://ai-passport-agent.codelife.me/>，USB 连接后选择「更新固件」。
兼容升级时保留「保留配置」，已存 Wi-Fi、助手和设备身份可以继续使用。
首次安装或完整替换可能清除配置，请先阅读[数据策略](../development/engineering/firmware-layout.zh_CN.md#刷写与已存数据)。

本版使用与 v0.7.4 相同的 OpenClaw 和 Hermes 插件接口，插件包为
`ai-passport-openclaw-0.7.5.tgz` 和 `ai-passport-hermes-0.7.5.tar.gz`。
替换插件文件后重启网关；两种后端共用同一份固件。

联网后蓝牙默认关闭；手机／网页蓝牙配置前在工牌「设置」中开启蓝牙。

## 构建与边界

使用 ESP-IDF 5.5.3，在对应标签源码运行 `./tools/validate.sh`；CI 从不可变标签重新构建、校验并回验发布附件。
原生 macOS／iOS App 仅保留源码，不构建、不分发。

自动关机修复已在维护设备上用缩短的计时实测：设备进入深度睡眠后保持关机，直到按下实体功能键才唤醒。不同硬件批次仍应自行检查实体按键和电池待机表现。

完整检查记录见[发布检查](readiness.zh_CN.md)。
