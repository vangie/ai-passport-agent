# AI Passport Agent v0.7.2

通话可靠性修复 · 2026-11-15

## 本版重点

- **通话不再无故中断。** 工牌周围有多人说话时，它会频繁打断回复。实时语音服务可能拒绝其中某一次请求，而会话本身仍然正常。旧固件把这次拒绝当成连接断开：关闭麦克风、显示「正在连接」，30 秒后放弃——麦克风关着，恢复信号不可能到来。现在工牌继续收音。
- **真正的故障仍有上限。** 连续超过五次这类错误且其间没有回复或转写、网关关闭会话，或 90 秒没有任何数据时，通话仍会带着网关的提示结束。
- **Hermes 采用相同规则。** 语音服务拒绝单个请求时，Hermes 插件不再结束已建立的通话。
- **诊断能说明是哪类故障。** OpenClaw 插件为每个上游错误记录固定词表里的类别，不记录错误原文；设备的通话诊断新增流阶段错误计数。

## 安装与升级

电脑 Chrome／Edge 打开 <https://ai-passport-agent.codelife.me/>，USB 连接后选择「更新固件」。
从兼容版本升级时保留「保留配置」勾选，已存 Wi-Fi、助手与设备身份可继续使用。
首次安装或完整替换可能清除配置，先阅读[数据策略](../development/engineering/firmware-layout.zh_CN.md#刷写与已存数据)。

按后端更新外置插件：`ai-passport-openclaw-0.7.2.tgz` 或 `ai-passport-hermes-0.7.2.tar.gz`。
固件侧的修复与 v0.7.1 插件兼容；Hermes 侧的修复需要新插件。
替换插件文件后重启网关：两种后端都不会在运行中重新加载插件。
两种后端共用固件；完整包为 `ai-passport-agent-firmware.tar.gz`。
命令行首次刷机使用 `agent-talk-full.bin` 从 `0x0` 写入；应用镜像 `agent-talk.bin` 只用于兼容更新至 `0x10000`。
校验 `SHA256SUMS.txt` 与 `release-manifest.json`，不公开设备授权、Wi-Fi 密码或模型密钥。

与 v0.7.1 相同，联网后蓝牙默认关闭；手机／网页蓝牙配置前在工牌「设置」开启蓝牙。

## 构建与边界

使用 ESP-IDF 5.5.3，在对应标签源码运行 `./tools/validate.sh`；发布流水线从不可变标签重新构建、校验并回验下载附件。
原生 macOS／iOS App 仅保留源码，不构建、不分发。

本次修复依据一次实际记录的故障在主机测试中复现；本地候选已刷入，并在两种后端上通过合成通话检查。
正式标签产物尚未重复多人说话的长时间真实通话。
记录到的那次故障没有保存上游错误原文，其类别是根据时间关系推断的。
网关各自限制通话时长：OpenClaw 在 30 分钟、Hermes 在 60 分钟时关闭通话，本版不改变这一点。
端侧人声检测不能排除所有噪声，附近的人声仍可能打断回复。

检查状态见[发布检查](readiness.zh_CN.md)。
