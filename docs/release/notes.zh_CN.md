# AI Passport Agent v0.7.4

在设备上调息屏和关机时间 · 2026-11-15

## 本版重点

- **两个闲置时间可以直接在设备上调。** 「设置」新增「息屏」和「关机」。各自打开一个调节页：上键把时间延长一档，中键缩短一档，到头的方向按键变灰。离开该页时保存并立即生效，不再需要电脑或配置网页。
- **档位和规则与配置网页一致。** 息屏 15 秒至 10 分钟；关机 5 分钟至 2 小时，或从不。把息屏调到晚于关机时，关机自动后移到下一个允许的档位；关机不能调到早于息屏。
- **设置列表可以滚动。** 设置现在有六项、显示四行，列表跟随选中项滚动，页眉显示当前是第几项。

## 安装与升级

电脑 Chrome／Edge 打开 <https://ai-passport-agent.codelife.me/>，USB 连接后选择「更新固件」。
从兼容版本升级时保留「保留配置」勾选，已存 Wi-Fi、助手与设备身份可继续使用。
首次安装或完整替换可能清除配置，先阅读[数据策略](../development/engineering/firmware-layout.zh_CN.md#刷写与已存数据)。

本版只改固件。两个插件除版本号外没有变化：
`ai-passport-openclaw-0.7.4.tgz` 和 `ai-passport-hermes-0.7.4.tar.gz` 的行为与 0.7.3 相同，0.7.3 的插件可以继续配合本版固件使用。
还没有安装 0.7.3 插件的 OpenClaw 用户，仍需安装它（或本版）才能获得 v0.7.3 的通话修复。
替换插件文件后重启网关：两种后端都不会在运行中重新加载插件。
两种后端共用固件；完整包为 `ai-passport-agent-firmware.tar.gz`。
命令行首次刷机使用 `agent-talk-full.bin` 从 `0x0` 写入；应用镜像 `agent-talk.bin` 只用于兼容更新至 `0x10000`。
校验 `SHA256SUMS.txt` 与 `release-manifest.json`，不公开设备授权、Wi-Fi 密码或模型密钥。

联网后蓝牙默认关闭；手机／网页蓝牙配置前在工牌「设置」开启蓝牙。

## 构建与边界

使用 ESP-IDF 5.5.3，在对应标签源码运行 `./tools/validate.sh`；发布流水线从不可变标签重新构建、校验并回验下载附件。
原生 macOS／iOS App 仅保留源码，不构建、不分发。

两个调节页用本地候选在一台设备上通过 USB 按键指令走过：打开页面、调档、离开时保存、离开前不生效、重启后仍保留、恢复原值。
没有用实体按键操作过，实机屏幕上的观感只在主机渲染里检查过。
保存失败时的提示由主机渲染覆盖，没有在实机上触发。
自动关机和按键唤醒与 v0.7.3 一样仍未在实机上观察到：测试设备一直连着电脑 USB，两个计时不会走。
真人说话并用声音打断的通话仍未重复。
