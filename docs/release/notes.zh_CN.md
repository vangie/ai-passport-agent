# AI Passport Agent v0.7.1

稳定性与体验更新 · 2026-11-14

## 本版重点

- **追问不离开对话。** 录音、发送和等待回复继续显示已有聊天；新内容自动跟随到底部，主动翻看历史时不抢走阅读位置。等待提示有动画，工作状态更直观。
- **连接更轻，噪声更少。** 优化校时、连接复用和 TLS 重连，减少重复准备。提问排除录音起始噪声与过短片段，修复较长录音可能发送失败的问题；首次连接速度和识别准确率仍取决于网络、服务商及网关模型。
- **屏幕更清楚。** 通话字幕有更多空间，简化助手设置和重复标签，平衡首页两个语音入口。电量图标与数字按三级变色，补齐文案及标点字形，不支持的笔记本 emoji 显示为单色键盘符号。
- **腾出资源给对话。** 缩减固件体积，联网时默认关闭蓝牙；需要配置时手动开启。固件下载统一为 `agent-talk.bin` 与 `agent-talk-full.bin`，网页继续识别历史版本。

## 安装与升级

电脑 Chrome／Edge 打开 <https://ai-passport-agent.codelife.me/>，USB 连接后选择「更新固件」。
从兼容版本升级时保留「保留配置」勾选，已存 Wi-Fi、助手与设备身份可继续使用。
首次安装或完整替换可能清除配置，先阅读[数据策略](../development/engineering/firmware-layout.zh_CN.md#刷写与已存数据)。

按后端更新外置插件：`ai-passport-openclaw-0.7.1.tgz` 或 `ai-passport-hermes-0.7.1.tar.gz`。
两种后端共用固件；完整包为 `ai-passport-agent-firmware.tar.gz`。
命令行首次刷机使用 `agent-talk-full.bin` 从 `0x0` 写入；应用镜像 `agent-talk.bin` 只用于兼容更新至 `0x10000`。
校验 `SHA256SUMS.txt` 与 `release-manifest.json`，不公开设备授权、Wi-Fi 密码或模型密钥。

**蓝牙行为有变化：** 联网后默认关闭；手机／网页蓝牙配置前在工牌「设置」开启蓝牙。
没有网络时自动开放配网，USB 配置不受影响。iPhone 使用 Bluefy，因为 Safari／Chrome 不支持网页蓝牙。

## 构建与边界

使用 ESP-IDF 5.5.3，在对应标签源码运行 `./tools/validate.sh`；发布流水线从不可变标签重新构建、校验并回验下载附件。
原生 macOS／iOS App 仅保留源码，不构建、不分发。

此前本地候选已完成刷入、启动及联网检查，用户确认可见界面变化；正式标签产物仍需独立实机验收。
端侧人声检测不能保证排除所有环境噪声，也不保证所有短句都被识别。
语音识别模型在网关配置，本版不内置 large-v3-turbo，也不把维护者主机的模型配置当成用户默认。
通话日常交流由实时语音模型处理，任务和个人上下文按需委托 Agent；设备暂不支持交互式工具审批。

检查状态见[发布检查](readiness.zh_CN.md)。
