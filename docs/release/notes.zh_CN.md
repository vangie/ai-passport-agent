# AI Passport OpenClaw v0.5.0

## 本版亮点

- **网页成为主入口：** 在 <https://ai-passport-openclaw.codelife.me/> 安装／更新固件和配置设备。
  电脑 Chrome／Edge 通过 USB 操作；兼容 Web Bluetooth 的浏览器可无线配置。
  iPhone 可使用 Bluefy 蓝牙配置，不支持手机刷机。
- **统一配置体验：** 已存 Wi-Fi、助手与各自线路、语言和音量集中管理；全局保存／撤销，
  失败保留草稿，逐步显示 Wi-Fi 扫描结果，并提供交给 Agent 执行的 OpenClaw 接入提示词。
- **明确的固件更新：** 默认保留配置进行兼容更新，首次安装／完整替换需显式选择并确认。
  网页同站点提供固件和依赖，不在运行时跳转 GitHub 下载；删除旧 Release 后仍识别旧固件版本。
- **蓝牙接管与屏幕优化：** 当前命令完成后进行加密配置端接管，按会话隔离回复并恢复广播；
  区分蓝牙连接状态，顶栏贯通，按键提示更紧凑对齐。
- **精简发布：** 只发布固件和可升级 OpenClaw 插件。原生客户端保留源码，不再构建、打包或宣传。

## 安装

从[配置网页](https://ai-passport-openclaw.codelife.me/)和[上手步骤](../../README.zh_CN.md#开始使用)开始。
首次安装／完整替换可能重置配置，兼容的应用更新保留配置；保存配置不会刷机。
新 Wi-Fi 首次保存时需要网络实际可达。

手动下载时，`FoloToy-AI-Passport.bin` 是写入 `0x10000` 的应用固件，
`FoloToy-AI-Passport-full.bin` 是写入 `0x0` 的完整固件，不要混用偏移。
固件压缩包包含刷写参数；`ai-passport-openclaw-0.5.0.tgz` 应安装在网关主机，而不是仅用于配置的电脑。

## 完整性与兼容性

发布前校验全部 7 个文件，记录源码提交和 SHA-256，先上传草稿并下载验证，再公开。
请核对 `SHA256SUMS.txt`。不分发个人 endpoint、Wi-Fi 密码、模型密钥或设备凭据。
网页没有应用后台，配置直接发给设备。

插件已验证基线仍为 OpenClaw 2026.10.5。通话需要配置实时语音服务，提问可独立使用。
构建、主机和浏览器测试不代表实机音质、电池、无线共存或所有浏览器兼容性验收。
