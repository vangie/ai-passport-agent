## 标题

随身搭档

## 简介

随身搭档，连接你自己的个人 Agent，支持 OpenClaw 与 Hermes。「提问」向助手问问题、交办任务，
回显你的话、逐步呈现文字回复，读完继续追问；「通话」进行连续语音交流，
配合滚动字幕，按屏幕提示静音、打断或结束。

连接的不是只有聊天能力的通用模型，而是你自己的助手及其已授权工具和上下文。
提问可使用 OpenClaw 专属助手，或 Hermes 原生个人 Agent；通话由实时语音模型处理日常交流，
需要任务、实时信息或私人上下文时可咨询 Agent，并非每句话都执行完整 Agent。

在浏览器配置与刷机：电脑 Chrome／Edge 通过 USB 安装、更新固件，兼容蓝牙浏览器修改设置，
iPhone 可用 Bluefy。把家中、办公室 Wi-Fi 和手机热点保存到设备，再按需切换已存网络。
配置网页没有应用后台、不中转对话；配置后设备通过 Wi-Fi 直连你的网关，手机不充当语音中继。

需自备已运行、有可用模型的 OpenClaw 或 Hermes。网页选择后端后复制提示词，交给能操作网关主机的
Agent，准备插件、安全可达入口与受限配对信息。远程访问可能需要自己的隧道资源与授权，
通话另需实时语音服务，服务商费用另计。这是独立社区开源项目，配图为真实界面的虚构数据渲染，非实机照片。

## 使用方法

1. 自备可用的 OpenClaw 或 Hermes。电脑 Chrome／Edge 打开 https://ai-passport-agent.codelife.me/，USB 连接并更新固件；首次取消「保留配置」，兼容更新可保留。
2. 「新增助手」选后端，将提示词交给网关主机的 Agent，填回地址和配对码；通话另需实时语音配置。扫描 2.4 GHz Wi-Fi，填密码并「保存配置」，Wi-Fi 图标亮起即成功。失败修改重试，过期配对码重取。
3. 「提问」按一下录音，再按或停顿发送，读完继续追问；「通话」等「正在听」后说话，按屏幕提示静音、打断或结束。
4. 「设置 → Wi-Fi」换已存网络；新增网络用网页 USB／蓝牙，蓝牙先在设备设置开启。iPhone 用 Bluefy；热点开启「允许其他人加入」「最大兼容性」，扫描不到时停留在个人热点设置页。
