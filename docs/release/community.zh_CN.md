## 标题

随身搭档

## 简介

随身搭档是连接你自己的个人 Agent 的语音入口，支持 OpenClaw 与 Hermes。使用「提问」处理问题和任务：查看自己的转写，阅读逐步出现的回复，并在同一段对话中继续追问；使用「通话」进行连续语音交流，通过字幕和屏幕按键静音、打断或结束。

它连接的是已经配置好的个人 Agent，而不是另一个普通聊天机器人。「提问」使用 Agent 已授权的工具和上下文；「通话」由实时语音模型处理日常交流，需要任务、实时信息或私人上下文时再咨询对应 Agent。

在网页中完成配置。电脑使用 Chrome／Edge 和 USB 安装或更新固件；需要移动配置时，可用支持网页蓝牙的浏览器（iPhone 使用 Bluefy）。保存家庭 Wi-Fi、办公室 Wi-Fi 和手机热点后，可在工牌上切换已保存网络。配置网页没有应用后台，也不转发对话；配置完成后，工牌通过 Wi-Fi 直接连接网关。

准备好自己的 Agent 后，设备就能成为一个轻量的语音入口：提问时看文字回复，通话时听语音应答。项目以开源方式提供，模型和语音服务由用户自己的网关配置。

## 使用方法

1. 准备可用的 OpenClaw 或 Hermes。电脑 Chrome／Edge 打开 https://ai-passport-agent.codelife.me/，USB 连接并更新固件；首次安装取消「保留配置」，兼容升级保留它。
2. 在「添加助手」中选择后端，把对应提示词交给网关主机上的 Agent，回填地址和配对码；「通话」还需要实时语音服务。扫描 2.4 GHz Wi-Fi，填写密码并保存；出现 Wi-Fi 图标表示连接成功，失败时修正后重试或重新生成过期配对码。
3. 「提问」按键开始录音，再按一次或停顿后发送，回复后可继续追问。「通话」等待显示「正在听」后说话，可按屏幕提示静音、打断或结束。设备闲置 1 分钟息屏、30 分钟自动关机，按任意功能键唤醒或开机；两个时间可在设备「设置」里的「息屏」「关机」调整。
4. 在「设置 → 网络」切换已保存网络。新增网络使用网页 USB／蓝牙配置；先在设备设置中开启蓝牙。iPhone 使用 Bluefy；配置个人热点时开启「允许其他人加入」和「最大兼容性」，找不到热点时先进入系统个人热点页面再回到网页扫描。
