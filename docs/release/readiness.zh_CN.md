## 故障与修复依据

2026-11-14 17:41 一次约 90 秒的 OpenClaw 通话异常结束，设备显示「网关实时语音服务出错」。
设备诊断为 `step=ready-timeout`、`voice_interrupts=4`、最低空闲堆 13,776 字节、分配失败 0 次。
网关日志显示：第四次语音打断时上游报错，网关发出 `session.error` 后会话继续接收音频；
设备此后停止上传，30 秒后网关记录 `session.closed`。
旧固件把通话中的流阶段错误当作连接断开并关闭麦克风，而恢复条件只有新的回复或转写事件，
麦克风关闭后无法满足。网关未记录上游错误原文，「被拒绝的打断请求」是根据时间关系得出的推断。
