# 配置与日常使用

## 项目名称与兼容性

AI Passport Agent 是产品名称，源码仓库为 `vangie/ai-passport-agent`；当前仅支持
OpenClaw。其插件的软件包名、ID、已有配置项及版本化 `.tgz` 包继续使用
`ai-passport-openclaw`，这是后端接入名称，而非产品主名称。

现有固件在 USB／蓝牙的 `HELLO` 消息中仍使用 `ai-passport-openclaw`。
此协议标识、蓝牙服务 UUID、原生客户端 Bundle ID、设备身份、NVS 存储及配对凭据均保持不变。
保留的原生客户端生成 `ai-passport-agent://` 配置链接，同时接受旧的
`ai-passport-openclaw://` 链接；原有 Wi-Fi 缓存路径也保持不变。更名不要求重新刷机或配对。

配置网页的固定 Pages 链接在域名迁移期间跟随当前生效域名。旧地址
`ai-passport-openclaw.codelife.me` 保留并跳转到 `ai-passport-agent.codelife.me`，
参见[旧地址兼容](web.zh_CN.md#旧地址兼容)。新地址可能需要重新授权浏览器 USB／蓝牙权限，
但设备配置不会改变。网站域名与社区页面更新独立处理，
均不改变用户的网关地址。
后续 Release 的固件压缩包使用 `ai-passport-agent-firmware.tar.gz`，已发布文件保留原名。

## 配置工具

使用[配置网页](https://vangie.github.io/ai-passport-agent/)。电脑 Chrome／Edge 支持 USB 配置和刷机；
兼容 Web Bluetooth 的浏览器支持无线配置。iPhone 请[在 App Store 获取 Bluefy](https://apps.apple.com/app/bluefy-web-ble-browser/id1492822055)，
安装后在 Bluefy 中打开配置网页，而非 Safari／Chrome。网页的蓝牙兼容提示也提供商店直达入口。
iPhone 的 Safari／Chrome 不提供网页蓝牙能力；Bluefy 支持这一功能，网页才能通过蓝牙配置 Passport。
Bluefy 仅用于配置，保存后即可关闭，Passport 会通过 Wi-Fi 独立连接 OpenClaw。
更新固件仍需电脑与 USB，参见[兼容性说明](web.zh_CN.md)。

## 让 OpenClaw 完成网关接入准备

在 OpenClaw 区域点击「复制提示词」，交给能够操作网关主机的 Agent；网关可以不是当前配置电脑。
网页不会自行安装服务端软件。需要准备：

- 已运行、有可用模型的 OpenClaw，以及 Agent 对网关主机的操作能力。
- Passport、首次刷机所需电脑／数据线，可达的 2.4 GHz Wi-Fi 或兼容手机热点。
- 外网接入所需隧道授权与可用 DNS／TLS。提示词复用已有入口；缺登录、权限或资源时会提示，
  不会自动提供账号、免费服务或新增付费授权。
- 通话需要实时语音服务；提问可以独立配置。

Agent 检查／安装兼容插件，准备专属 `passport` 助手、转写／模型设置和持久公网 WSS 入口。
修改前备份，保留设备认证和回环监听，仅在必要时重启。先检查 DNS／TLS／WebSocket，
再返回受限配对码；这不是麦克风实机验收。将地址和配对码填回网页，与 Wi-Fi 一并保存。
过期或已使用的配对码需要重新生成；不要把管理员 token 或模型 Key 填入设备。

手动或仅局域网接入见[插件指南](../tools/openclaw/README.zh_CN.md)和[网络与安全](networking.zh_CN.md)。
工具权限在专属 agent 限制；助手配置选择连接，不是任意切换提问 agent ID。

## 连接、保存与撤销

1. 通过 USB／蓝牙连接并读取设备。蓝牙名称是 **AI Passport XXXX**，可在设备设置开启蓝牙。
   如果 USB 能看到设备而蓝牙发现不到，可先重启 Passport 再扫描。
2. 扫描或输入 Wi-Fi 名称与密码。由 **Passport** 而不是浏览器扫描附近网络，新版固件会逐步返回结果。
3. 编辑 Wi-Fi、助手／线路、屏幕语言和音量，点击「保存配置」。没改动的项目不需要重复配对。
4. 等待确认与回读。失败或重连保留草稿；「撤销」恢复最近读取／确认的状态，
   不撤销已成功写入，也不能复原已消耗的一次性配对码。

多项保存 **不是原子事务**：后续失败，前面的成功项仍保留。新网络保存前会试连，目标必须可达。
扫描无结果仍可手动输入。测试在设备上执行，不会改变电脑／手机的 Wi-Fi 连接。
设备连接检查验证认证、会话权限和实时配置，不代表模型回答、音质或长时间通话验收。

## 语音过滤

提问和通话使用轻量的端侧 WebRTC 人声活动检测，不再只根据音量判断。
提问在确认有人声、随后安静约两秒时自动提交；手动提交但没有检测到人声时，
丢弃本次录音，不发送给助手，已完成的聊天记录保留。取消和重录操作不变。

通话把未确认的麦克风噪声替换为静音，保留最多 171 毫秒的压缩预录，
尽量保住开头的音节。静音和播放保护会清空预录；语音打断还需要在回声检查
探测期间确认人声，按键打断不要求人声。队列满时丢弃最旧的预录并计入音频
诊断，避免把开头延后乱序发送。

这不是声纹识别，也不能保证完全没有误触发。电视、旁人说话、音乐及较强的
类人声噪声仍可能通过，过短、过轻或距离较远的人声可能漏检。
当前主机素材覆盖多档音量的人声、静音、直流、敲击、白噪声、低强度滤波噪声
和工频嗡声；较大滤波噪声仍可能误触发。还需要实机验证麦克风、嘈杂环境、
轻声说话和打断体验。

检测器只在采集期间占用约 948 字节堆内存。通话新增 2,144 字节压缩预录，
同时去掉原来的 1,536 字节 PCM 起始缓冲；提问和通话不会同时分配两套检测器。
测试音频不打入固件。参见[来源与许可](../assets/README.zh_CN.md#语音检测测试素材)。

## 配置保存在哪里

Passport 是配置的权威来源：最多 **8 套网络、4 套助手连接**，以及语言、音量。
设备保存连接凭据，模型／服务商 Key 留在 OpenClaw。网页没有应用后台，通过 USB／蓝牙直接配置；
密钥草稿只在页面内存，不写浏览器持久存储，刷新／关闭后丢弃。
静态托管可能记录 IP／时间等常规访问日志，不包括页面未上传的配置。

干净固件不含个人网关、代理或模型 Key。示例使用虚构网络与 `.example` 地址。
不要公开配置导出、设备内存转储、配对码或未脱敏日志。

原生客户端仅保留源码供开发者参考。旧桌面客户端的历史 Wi-Fi 缓存是
`~/Library/Application Support/AI Passport OpenClaw/` 下未加密、仅当前用户可读的 `wifi.json`，
应将文件与备份视为敏感内容；它不属于网页流程或浏览器存储。

## 安装与更新固件

保存配置不会刷机。默认勾选「保留配置」，通过 USB 进行兼容应用更新，保留设备数据。
首次安装／完整替换时取消勾选，确认「安装固件」；该操作可能覆盖配置。
两种模式都不整片擦除。网页同站点提供验证过的发布固件，无需本地选文件或跟随 GitHub 下载跳转。

应用固件写入兼容分区的 `0x10000`，完整固件写入 `0x0`，不要混用。
没有自动还原原厂固件的功能，参见[固件布局与数据策略](development/engineering/firmware-layout.zh_CN.md)。

## iPhone Wi-Fi 与热点

在 Bluefy 打开网页，蓝牙连接后在 Wi-Fi 区域扫描。不读取 iOS 已存密码，新密码需自己输入；
已有网络可复用设备保存的密码。链状图标是尽力识别的 Apple 热点，不代表所有权或保证识别。

### 不安装 iOS App，提前配置手机热点

1. 打开 iPhone「设置 → 个人热点」，开启「允许其他人加入」「最大兼容性」，查看名称与密码。
   扫描不到时，请停留在该设置页面。
2. 用电脑 USB 或 Bluefy 蓝牙连接配置网页，选择／填写热点并保存；首次试连时手机必须在附近并开启热点。
   网页没有可靠受支持的链接直接跳到该系统设置页。
3. 日后开启相同热点，在设备「设置 → Wi-Fi」选择；回家／办公室也在此切换，不需重新配对助手。

配置后可以关闭浏览器，供网期间保持热点开启。热点本身不会暴露家中网关，见[网络接入](networking.zh_CN.md)。

## 蓝牙行为与安全

待机默认开启蓝牙。启动先给 Wi-Fi 最多 10 秒，之后启用 BLE；手动开启可跳过等待，设备设置内可直接切换。
状态图标暗表示已开启，亮蓝／加粗表示配置端已连接，关闭后隐藏；不代表配置保存成功或网关已认证。

固件保留加密客户端绑定。新端完成加密配置握手后可接管，先等当前工作结束，回复按发起会话隔离。
旧网页保留草稿，不会自动抢回。Just Works 加密不验证所有权，也不防主动中间人攻击，请在可信环境配置。

录音、通话及网关操作会临时释放 BLE 内存并断开配置端，清理后恢复。
Wi-Fi 保存／扫描不主动关闭配置蓝牙。旧固件可能需先 USB 更新才能安全配置；系统配对提示因浏览器而异。

## NFC 与个人热点

无源标签独立于固件和设备电源触发 iPhone 自动化，不认证用户、不下发 Wi-Fi，也不唤醒设备处理器。
已测试标签为 NTAG213，用户存储 144 字节。

1. 先通过网页保存并测试手机热点。
2. 打开「快捷指令 → 自动化 → NFC」，扫描标签，支持时选择「立即运行」，添加「设定个人热点 → 打开」。
   不用「切换」，避免第二次碰触反而关闭。
3. 手机亮屏测试；没有效果时检查自动化权限与确认设置。

原厂 URL 仍弹网页通知时，用 NFC 工具备份后将 URL **替换**为普通文本记录（`AI Passport`），
不要追加在网址后，也不要改 UID、锁定位或配置区。维护者 iPhone 已验证有效；USB 刷机不改 NFC。
不要写入密码与配对凭据；不同 iOS 版本表现可能不同。
